# 企业发票付款放行与反舞弊门禁

Copyright © 2026 上海如静知华信息科技有限公司 · <https://www.zhuatech.cn/>

`POST /api/enterprise/invoice/payment-release` 在生成付款批次前校验发票真实性、三单匹配、重复付款、供应商状态、税务规则、制裁筛查、收款账户变更、争议止付、预算、审批人数和职责分离。

接口返回 `RELEASE / SECOND_APPROVAL / HOLD / BLOCKED`，并生成由发票、供应商和金额组成的 SHA-256 付款指纹。未独立回拨验证的银行账户变更、重复风险和申请人自批会直接阻断；预算或争议问题进入止付；审批不足进入审批队列。

AI/OCR 可以辅助识别票面和异常，但付款放行只由确定性财务控制作出，任何模型结果都不能绕过供应商、银行账户、预算和审批门禁。
